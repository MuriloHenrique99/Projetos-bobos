Comandos de seleção

Veja aqui
  • ls *.txt | ls acucar* | ls *vermelho*

    //o * seleciona todos do tipo que voce determinar, estou usando o comando listar com * isso faz o seguinte
    // *.txt seleciona tudo que termine com .txt
    // acucar* seleciona tudo que comece com acucar
    // *vermelho* acessa todos os arquivos que tenham a palavra vermelho

  • img? arquivo? .?x?

    //comando ?, onde ele estiver significa que esta buscando qualquer caracter naquela posicao
    //exemplo img? que caso exista img1, img2, img3 todas irão aparecer como resultado
    //uma utilidade é tirar arquivo chato .exe e txt de pastas grandes, vc joga o .?x? e tudo que tiver
    //. como primeiro caracter e x como terceiro ira aparecer

  • file[123].txt file[1-9] file[a-z] file[!45] file[!0-9]

    //esse comando seleciona intervalos de caracteres que pode aparecer
    //exemplo [123] se o arquivo tive 1 ou 2 ou 3 naquela posicao ele é valido como saida
    //pra facilitar existem intervalos com [0-9] se tiver entre 0 e 9 passa
    //tambem existe o ! que exclui os selecionados [!0-9] se tiver numero de 0 a 9 nao aparece

  • ;

    //esse comando simples permite utilizar varios comandos em uma mesma linha

  • tr 'algo' 'outro' tr ' ' '\n'
    //tr é uma troca de palavras nesse primeiro exemplo algo é trocado por outro e no segundo exemplo linhas em branco sao trocadas por quebras de linhas, isso organiza textos

Modificações em Arquivos e Pastas

Veja aqui

  • cp texte.txt teste.txt
    //copia o arquivo texte e renomeia como teste

  • cp teste.txt pasta/
    //copia e leva para a pasta inserida

  • cp teste.txt pasta/tst.txt
    //copia e leva para a pasta inserida e renomeia para tst

  • cp -r pasta nova_pasta
    //copia a pasta toda e nomeia como nova_pasta

  • cp -r pasta nova_pasta/
    //copia a pasta para dentro de nova_pasta

  • mv arquivo.txt teste.txt
    //renomeia arquivo para teste

  • mv arquivo.txt pasta/
    //move para a pasta selecionada

  • rm arquivo.txt
    //deleta o arquivo

  • rm arquivo1.txt arquivo2.txt
    //deleta mais de 1

  • rm -r pasta
    //remove pasta

  • rm -f -r pasta
    //-f forced, -r diretorio, remove a pasta forcadamente

  • rm -r pasta ou rm -rf pasta
    //remove uma pasta, se vc utilizar o -rf remove forçadamente a pasta
    //existe tambem o rmdir pasta mas ele remove apenas pastas vazias entao ignore-o

  • cat teste.txt
    // apresenta arquivo, recomendado para arquvo pequenos

  • less teste.txt
    // apresenta arquivo, recomendado para arquivos grandes, é o que vai ser utilizado na maior parte das veses

  • head/tail -n 10 arquivo
    //isso le 10 linhas do arquivo no topo para head e no fim para tail

  • wc arquivo
    //wc lista quantas linhas,palavras e caracteres tem no arquivo
    //wc -l lista as linhas
    //wc -w lista as palavras
    //wc -c lista os caracteres

  • sort arquivo
    lista as palavras do arquivo em ordem alfabetica
    sort -r arquivo; sort -u arquivo; sort -n arquivo
    //-r lista em ordem decrescente
    //-u lista ignorando duplicatas
    //-n lista por numeros

  • grep "mensagem" arquivo
    //todas as linhas que tiverem a(s) palavras selecionadas serão listadas
    grep -i "erro" arquivo
    //ignora letras maiusculas ou minusculas
    grep -v
    //exibe linhas não correspondentes
    grep -n
    //mostra o numero da linha que encontrou
    grep -r
    //mostra as pastas que possui a mensagem
    grep -l
    //mostra os arquivos que possuem a mensagem
    grep -in
    //ignora letras e mostra a linha, é possivel misturar a vontade

  • echo "mensagem"
    //comando print de terminal

  • ls algo > arquivo
    //isso lista algo dentro de arquivo, é um comando de direção

  • echo "oi" >> arquivo
    //coloca oi no arquivo mas sem sobrescrever o que tinha antes

  • echo $HOME SHELL PWD USER
    // o echo com $ mostra o valor da variavel que vier depois, nesse caso ele mostra o caminho da pasta pessoal(HOME)
    //USER mostra seu nome de usuario, SHELL seu programa de shell atual e PWD diretorio de trabalho atual

  • echo < "oi" > arquivo
    //isso diz pra echo que oi é vinculado a arquivo
    echo < arquivo > "oi"
    //aqui sim é util o < pois ele se torna um intermediador

  • cat arquivo | sort
    //pega a saida de cat e envia para sort, no fim é listado ordenado na tela
    //faz o que cat < arquivo > sort faria basicamente
    cat arquivo | sort | uniq | head -10
    //o comando | é util pra fazer multiplas operações desta forma
    //nesse exemplo ele mostra as 10 primeiras linhas sem duplicatas e ordenadas por nome

  • -rwx rwx rwx drwx r-x --x
    //esse comando mostra as permissões de cada tipo de usuario no sistema, o comando é tudo junto -rwxrwxrwx
    //a primeira letra pode ser - ou d, - é arquivo padrao e d é pasta
    //rwx é read, write e execute, a ordem é proprietario,grupo e usuario padrao sempre divido em 3
    //dessa forma -rwx <--1 rwx <--2 rwx <--3
    //o segundo exemplo é pra caso deseje retirar permissões colocando - onde seria a permissao
    //drwx r-x --x, nesse comando o proprietario faz tudo, grupos podem ler e executar e usuarios normais podem apenas executar

  • chmod 777 cat arquivo.txt
    //esse comando facilita tudo é dividido pelo seguinte
    //7 para todas as permissões(rwx)
    //6 para leitura e escrita(rw-)
    //5 para leitura e execução(r-x)
    //4 apenas leitura(r--)
    //0 para nenhuma permissão

  • chown nome arquivo chown :nome arquivo
    //o comando chown nome arquivo troca o proprietario do arquivo pro nome que foi inserido
    //chown :nome arquivo altera o grupo que ele pertence

  • printenv printenv HOME
    //isso mostra todas as variaveis do ambiente enquanto printenv HOME mostra só as variaveis HOME

  • cat > backup.sh << 'EOF'
    #!/bin/bash
    read -p "Enter source directory: " source_dir
    echo "Backing up: $source_dir"
    backup_dir="backup"
    mkdir -p "$backup_dir"
    echo "Created backup folder: $backup_dir"
    cp "$source_dir"/* "$backup_dir"
    echo "Files copied successfully"
    EOF
    echo "documents" | bash backup.sh
    ls backup

    //Cria um script básico que pede uma pasta de origem via 'read', cria uma pasta fixa chamada backup (usando mkdir -p para não dar erro se já existir) e copia todos os arquivos soltos dela.
    //O comando 'echo "documents" | bash backup.sh' executa o script enviando a palavra documents automaticamente para o read.
    //O 'ls backup' no final lista o conteúdo copiado para conferência.

  • cat > backup.sh << 'EOF'
    #!/bin/bash
    echo "Enter folder to backup:"
    read folder
    echo "Backing up: $folder"
    timestamp=$(date +%Y%m%d_%H%M%S)
    backup_dir="backup_$timestamp"
    mkdir "$backup_dir"
    echo "Created backup folder: $backup_dir"
    cp "$folder"/* "$backup_dir"/
    echo "Files copied successfully"
    EOF
    chmod +x backup.sh
    echo "documents" | bash backup.sh

    //Nesta versão, a data/hora exata é salva primeiro na variável 'timestamp' usando $(date +%Y%m%d_%H%M%S).
    //Depois, cria a pasta com o nome dinâmico (ex: backup_20260914_150500), garantindo que backups antigos nunca sejam sobrescritos.
    //Usa 'echo' e 'read' em duas linhas separadas no lugar de 'read -p'. Usa 'chmod +x' para dar permissão de execução ao script.

  • cat > backup.sh << 'EOF'
    #!/bin/bash
    read -p "Enter directory to backup: " source_dir
    echo "Backing up: $source_dir"
    backup_dir="backup_$(date +%Y%m%d_%H%M%S)"
    mkdir "$backup_dir"
    echo "Created backup folder: $backup_dir"
    cp "$source_dir"/* "$backup_dir"/
    echo "Files copied successfully"
    echo "Backup complete: $source_dir -> $backup_dir"
    EOF
    echo "documents" | bash backup.sh

    //Versão mais limpa, gera o timestamp diretamente dentro da declaração da variável 'backup_dir'.
    //Inclui um 'echo' final informativo mostrando exatamente qual pasta foi copiada e qual pasta de destino foi gerada ($source_dir -> $backup_dir).
